\# ACE-PeptideNet



ACE-PeptideNet is an interpretable machine learning framework for the prediction of ACE-inhibitory peptides.



\## 🌐 Online Demo



The online prediction platform is available at:



https://ace.peptideinnov.com





\## Overview



ACE-PeptideNet provides an intelligent prediction system for ACE-inhibitory peptide activity based on machine learning methods and peptide sequence-derived features.



Users can directly submit peptide sequences through the web interface and obtain prediction results.





\## Features



\- Single peptide sequence prediction

\- Batch prediction from CSV/XLSX files

\- Machine learning-based ACE-inhibitory activity classification

\- Web-based interactive prediction interface





\## Usage



1\. Open the online platform:

&#x20;  

&#x20;  https://ace.peptideinnov.com



2\. Enter a peptide sequence or upload a batch file.



3\. Submit the prediction request.



4\. View the predicted ACE-inhibitory probability and classification result.
